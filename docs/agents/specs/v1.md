# Project Proposal: Light Reader

**Minimal single-page webview tool for Light Phone III — reader-first rendering, fixed chrome, no editable address bar.**

---

## 1. Summary

Light Reader is a LightOS tool built on `light-sdk` and `light-keyboard`. It renders one URL at a time inside an embedded `WebView`, applies a monochrome LightOS-aligned base theme to all pages, and defaults to a reader transformation for prose content. Navigation is limited to back, forward, reload, reader/original toggle, and an explicit URL modal. The address is displayed as truncated read-only text. All code lives in the `:tool` module and must pass the unmodified official SDK plugin, lint, and containerized builder.

## 2. Objectives and non-goals

### Objectives

| #   | Objective                                                                                                          |
| --- | ------------------------------------------------------------------------------------------------------------------ |
| O1  | Single-screen webview tool compliant with the official `light-sdk` screen model                                    |
| O2  | Reader mode on by default for eligible prose pages; one-tap toggle to themed original                              |
| O3  | Base theme injection forcing high-contrast monochrome presentation on forms, buttons, and body content             |
| O4  | Minimal fixed navigation chrome; no persistent editable address bar                                                |
| O5  | URL entry via modal using `light-keyboard` embedded Compose keyboard                                               |
| O6  | Strict security posture: scheme allowlist, TLS failure cancel, no JavaScript bridge, no external activity launches |
| O7  | Pass unmodified official plugin/lint build and the official offline containerized builder                          |

### Non-goals

| #   | Exclusion                                               | Reason                                                                       |
| --- | ------------------------------------------------------- | ---------------------------------------------------------------------------- |
| N1  | Tabs or multi-window browsing                           | Single-page scope; `setSupportMultipleWindows(false)`                        |
| N2  | History, bookmarks, downloads                           | Persistence scope limited to reader preference and optional last URL         |
| N3  | External app handoff (`tel:`, `mailto:`, `intent:`)     | SDK blocks `startActivity()`; out of scope                                   |
| N4  | Embedded keyboard for arbitrary web form fields         | Requires focus tracking, selection sync, and trusted JS bridge; deferred     |
| N5  | `addJavascriptInterface` native bridge                  | Unnecessary for one-way injection; expands attack surface on untrusted pages |
| N6  | Destructive DOM rewriting of the live application tree  | Breaks SPA frameworks; reader clones instead                                 |
| N7  | Third-party JVM reader libraries (Readability4J, Jsoup) | Not on the official dependency allowlist                                     |

## 3. Architecture

```text
:tool module
│
├── BrowserScreen (@InitialScreen)
│   LightScreen<Unit, BrowserViewModel>
│   └── Compose: LightTheme → Column
│       ├── Status row   (truncated URL, read-only)
│       ├── AndroidView  (WebView, weight 1f)
│       └── Nav row      (Back / Fwd / Reload / Reader / URL)
│
├── BrowserViewModel : LightViewModel<Unit>
│   └── StateFlow<BrowserUiState> — no WebView reference held
│
├── LightWebViewClient : WebViewClient
│   ├── onPageCommitVisible → inject base theme (early, anti-flash)
│   ├── onPageFinished      → inject boot script + reader pass
│   ├── shouldOverrideUrlLoading → scheme allowlist
│   └── onReceivedSslError  → handler.cancel()
│
├── ScriptInjection
│   └── assets → JSON-encoded strings → evaluateJavascript (one-way)
│
├── assets/
│   ├── light-page-theme.css   (base theme: forms, buttons, typography)
│   ├── reader-theme.css       (reader layout)
│   └── page-hooks.js          (idempotent boot, SPA hooks, debounced observer)
│
└── UrlEntryModal
    └── Lp3KeyboardWrapper (light-keyboard) + URL normalization
```

Reader conversion executes as injected JavaScript against the rendered DOM — no JVM HTML parser dependency. WebView performs all network loading; OkHttp (allowlisted) is available but unused in MVP.

## 6. User stories

| ID   | Story                                                                                                   | Acceptance criteria                                                                      |
| ---- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| US1  | As a user, I want pages to open in reader view by default so that articles are immediately readable.    | Eligible prose page renders extracted content in reader layout without user action       |
| US2  | As a user, I want to switch to the original page so that interactive content still works.               | Toggle restores original DOM; forms and scripts functional; toggle back re-extracts      |
| US3  | As a user, I want buttons and forms to look like LightOS so that the experience is visually consistent. | Semantic controls render monochrome, square, high-contrast, with visible focus ring      |
| US4  | As a user, I want to go back and forward within the site so that I can recover from mis-taps.           | Nav row reflects `canGoBack`/`canGoForward`; no external browser opens                   |
| US5  | As a user, I want links to stay inside the tool so that I am never thrown into another app.             | All https navigations remain in WebView; blocked schemes show status, no activity launch |
| US6  | As a user, I want to type a URL only when I choose to so that the screen stays minimal.                 | Address is read-only text; keyboard modal appears only on explicit URL action            |
| US7  | As a user, I want the tool to remember my reader preference so that I do not reconfigure it.            | Reader default persists across launches via DataStore                                    |
| US8  | As a user, I want clear feedback when a page fails so that I know the tool is not frozen.               | TLS/DNS/offline/renderer failures produce explicit error state with reload affordance    |
| US9  | As a user, I want reader mode to leave login and checkout pages alone so that I can complete tasks.     | Eligibility gate skips non-prose pages; base theme still applied                         |
| US10 | As a user, I want SPA navigation to keep the theme so that route changes do not flash unstyled content. | `pushState`/`hashchange` trigger debounced re-theme; no full-page unstyled flash         |

### 8.3 `BrowserScreen.kt`

```kotlin
@InitialScreen
class BrowserScreen(
    sealedActivity: SealedLightActivity
) : LightScreen<Unit, BrowserViewModel>(sealedActivity) {

    override val viewModelClass: Class<BrowserViewModel>
        get() = BrowserViewModel::class.java

    override fun createViewModel(): BrowserViewModel = BrowserViewModel()

    @Composable
    override fun Content() {
        val themeColors by LightThemeController.colors.collectAsState()
        val state by viewModel.uiState.collectAsState()
        val webViewRef = remember { mutableStateOf<WebView?>(null) }

        LightTheme(colors = themeColors) {
            Column(
                Modifier
                    .fillMaxSize()
                    .background(LightThemeTokens.colors.background)
            ) {
                // Read-only status row
                LightText(
                    text = state.committedUrl?.take(38) ?: state.requestedUrl.take(38),
                    variant = LightTextVariant.Body,
                    modifier = Modifier.padding(horizontal = 16.dp, vertical = 8.dp)
                )

                AndroidView(
                    modifier = Modifier
                        .fillMaxWidth()
                        .weight(1f),
                    factory = { context ->            // inferred; no Context import
                        WebView(context).apply {
                            settings.apply {
                                javaScriptEnabled = true
                                domStorageEnabled = true
                                allowFileAccess = false
                                allowContentAccess = false
                                setSupportMultipleWindows(false)
                                javaScriptCanOpenWindowsAutomatically = false
                                mixedContentMode = WebSettings.MIXED_CONTENT_NEVER_ALLOW
                            }
                            setBackgroundColor(android.graphics.Color.WHITE)
                            webChromeClient = WebChromeClient()
                            webViewClient = LightWebViewClient(
                                injection = ScriptInjection(assets),
                                onState = viewModel::onWebState
                            )
                            loadUrl(state.requestedUrl)
                            webViewRef.value = this
                        }
                    }
                )

                NavRow(
                    state = state,
                    onBack = {
                        val wv = webViewRef.value
                        if (wv?.canGoBack() == true) wv.goBack() else viewModel.requestExit()
                    },
                    onForward = { webViewRef.value?.takeIf { it.canGoForward() }?.goForward() },
                    onReload = { webViewRef.value?.reload() },
                    onToggleReader = {
                        viewModel.toggleReader()
                        webViewRef.value?.evaluateJavascript(
                            "window.__lightSetReaderEnabled(${state.readerRequested.not()})", null
                        )
                    },
                    onOpenUrl = { viewModel.showUrlEditor(true) }
                )

                if (state.urlEditorVisible) {
                    UrlEntryModal(
                        current = state.committedUrl ?: state.requestedUrl,
                        onSubmit = { url ->
                            viewModel.submitUrl(url)
                            webViewRef.value?.loadUrl(url)
                        },
                        onDismiss = { viewModel.showUrlEditor(false) }
                    )
                }
            }
        }
    }
}
```

### 8.4 `BrowserViewModel.kt`

```kotlin
class BrowserViewModel : LightViewModel<Unit>() {

    private val _uiState = MutableStateFlow(
        BrowserUiState(requestedUrl = "https://example.com")
    )
    val uiState: StateFlow<BrowserUiState> = _uiState

    fun onWebState(update: WebStateUpdate) {
        _uiState.update {
            it.copy(
                committedUrl = update.url ?: it.committedUrl,
                loading = update.loading,
                canGoBack = update.canGoBack,
                canGoForward = update.canGoForward,
                readerApplied = update.readerApplied,
                error = update.error
            )
        }
    }

    fun toggleReader() = _uiState.update {
        it.copy(readerRequested = !it.readerRequested)
    }

    fun showUrlEditor(visible: Boolean) = _uiState.update {
        it.copy(urlEditorVisible = visible)
    }

    fun submitUrl(raw: String) = _uiState.update {
        it.copy(requestedUrl = UrlNormalizer.normalize(raw), urlEditorVisible = false)
    }

    fun requestExit() { /* LightScreen back/exit path per pinned SDK */ }
}
```

The WebView instance never enters the ViewModel. Commands flow one-way through the Compose layer.

### 8.6 `LightWebViewClient.kt`

```kotlin
class LightWebViewClient(
    private val injection: ScriptInjection,
    private val onState: (WebStateUpdate) -> Unit
) : WebViewClient() {

    override fun shouldOverrideUrlLoading(
        view: WebView,
        request: WebResourceRequest
    ): Boolean {
        val allowed = BrowserPolicy.isAllowed(request.url)
        if (!allowed) onState(WebStateUpdate(url = view.url))
        return !allowed   // consume blocked schemes; never launch externally
    }

    override fun onPageCommitVisible(view: WebView, url: String?) {
        super.onPageCommitVisible(view, url)
        injection.injectBaseTheme(view)
    }

    override fun onPageFinished(view: WebView, url: String?) {
        super.onPageFinished(view, url)
        injection.injectBootScript(view)
        onState(
            WebStateUpdate(
                url = url,
                canGoBack = view.canGoBack(),
                canGoForward = view.canGoForward()
            )
        )
    }

    override fun onReceivedSslError(
        view: WebView,
        handler: SslErrorHandler,
        error: SslError
    ) {
        handler.cancel()
        onState(WebStateUpdate(error = BrowserError.Tls))
    }

    override fun onRenderProcessGone(
        view: WebView,
        detail: RenderProcessGoneDetail
    ): Boolean {
        onState(WebStateUpdate(error = BrowserError.RendererGone))
        return true
    }
}
```

### 8.7 `ScriptInjection.kt`

```kotlin
class ScriptInjection(assets: AssetManager) {

    private val baseCss = assets.open("light-page-theme.css")
        .bufferedReader().readText()
    private val readerCss = assets.open("reader-theme.css")
        .bufferedReader().readText()
    private val hooksJs = assets.open("page-hooks.js")
        .bufferedReader().readText()

    // JSON string encoding prevents quote/newline/control-char escape failures
    private fun String.asJsString(): String = JSONObject.quote(this)

    fun injectBaseTheme(view: WebView) {
        view.evaluateJavascript(
            """
            (function(){
              var s = document.getElementById('__light_base_theme')
                   || document.createElement('style');
              s.id = '__light_base_theme';
              s.textContent = ${baseCss.asJsString()};
              (document.head || document.documentElement).appendChild(s);
            })();
            """.trimIndent(),
            null
        )
    }

    fun injectBootScript(view: WebView) {
        val payload = hooksJs
            .replace("__BASE_CSS__", baseCss.asJsString())
            .replace("__READER_CSS__", readerCss.asJsString())
        view.evaluateJavascript(payload, null)
    }
}
```

### 8.8 `assets/page-hooks.js` (boot core)

```javascript
(() => {
  if (window.__lightToolInstalled) {
    window.__lightToolRefresh && window.__lightToolRefresh();
    return;
  }
  window.__lightToolInstalled = true;
  window.__lightReaderEnabled = true;

  const ensureStyle = (id, css) => {
    let s = document.getElementById(id);
    if (!s) {
      s = document.createElement("style");
      s.id = id;
      (document.head || document.documentElement).appendChild(s);
    }
    s.textContent = css;
  };

  let timer = null;
  const schedule = () => {
    clearTimeout(timer);
    timer = setTimeout(() => window.__lightToolRefresh(), 250);
  };

  ["pushState", "replaceState"].forEach((fn) => {
    const orig = history[fn];
    history[fn] = function (...a) {
      const r = orig.apply(this, a);
      schedule();
      return r;
    };
  });
  addEventListener("popstate", schedule);
  addEventListener("hashchange", schedule);

  new MutationObserver(schedule).observe(document.documentElement, {
    childList: true,
    subtree: true,
  });

  window.__lightSetReaderEnabled = (on) => {
    window.__lightReaderEnabled = !!on;
    if (on) applyReaderMode();
    else restoreOriginal();
  };

  window.__lightToolRefresh = () => {
    ensureStyle("__light_base_theme", __BASE_CSS__);
    if (window.__lightReaderEnabled && isReaderEligible()) applyReaderMode();
  };

  // isReaderEligible / applyReaderMode / restoreOriginal defined below (M3)
```

## 10. Acceptance and compliance gate

The project is complete when all of the following hold:

1. User stories US1–US10 pass on physical LP3 hardware.
2. Test matrix (§7) green, or every failure logged with severity and disposition.
3. `./gradlew :tool:clean :tool:assembleDebug :tool:lint :tool:test` passes against the **unmodified** pinned SDK.
4. Official containerized offline builder produces an installable artifact.
5. APK installs via ADB and passes the smoke sequence: launch → reader render → toggle → navigate → URL modal → exit.
